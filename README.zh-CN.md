## 使用

先按 [英文 README](README.md) 创建环境，再按 [完整复现说明](docs/REPRODUCING.md) 解包数据和运行。大数据留在 Zenodo；GitHub 只放本目录。每次运行会创建独立输出目录，不覆盖存档结果。

原始服务器路径保留在 `original/` 中作为来源记录。新增启动器会在副本中修改路径，并记录修改前后的哈希。
